# IPL Cricket Data Analysis

## Overview
This project performs Exploratory Data Analysis (EDA) on Indian Premier League (IPL) match and ball-by-ball datasets using Python. The analysis uncovers player performances, team statistics, match trends, and scoring patterns through data cleaning, visualization, and statistical insights.

## Objectives
- Analyze historical IPL match data to identify performance trends.
- Clean and preprocess raw datasets for accurate analysis.
- Visualize batting, bowling, team, and venue statistics.
- Generate insights into match outcomes and scoring patterns.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analyses
- Top run scorers, wicket takers, and fielders
- Team win percentages and championship distribution
- Toss impact on match outcomes
- Venue-wise average runs and wickets
- Powerplay, Middle Overs, and Death Overs scoring patterns

## Key Insights
- Identified the most consistent players and successful franchises.
- Evaluated how toss decisions influence match results.
- Compared scoring trends across different phases of an innings.
- Highlighted venue-specific batting and bowling characteristics.

## Dataset
- IPL Matches Dataset
- IPL Ball-by-Ball Dataset
